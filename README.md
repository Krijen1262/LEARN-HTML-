# LEARNING-HTML
Assignment Title
HTML Basics and Semantic Elements Assignment


Brief Description

This assignment contains four separate exercises designed to demonstrate the fundamentals of HTML5. It covers basic webpage structure, forms, tables, and semantic HTML elements. Each exercise is implemented using correct HTML tags and simple, readable code.

Exercises Included

Exercise 1 – Simple Web Page 

Title- My Learnings for HTML

Basic HTML structure with headings, paragraphs, lists, links, and an image.

Exercise 2 – HTML Form 
Title- Basic Information

A form with text input, radio buttons, checkboxes, textarea, and submit button.

Exercise 3 – HTML Tables
Title-Data Tables

A table with headers, multiple rows, merged cells, borders, and a caption.

Exercise 4 – Semantic HTML Elements
Title-Krijen Shahi - Semantic CV Page

Webpage using semantic tags such as header, nav, article, aside, and footer with comments explaining each section.
